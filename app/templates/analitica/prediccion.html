¿Cómo se calcula esta predicción y cómo leerla?

El sistema estima cuántas unidades de cada producto se venderán el próximo mes, a partir de las ventas reales de la Sede Pimentel (enero 2023 en adelante, hasta {{ ejecucion.datos_hasta }}). Se agrupan los tamaños de un mismo producto (por ejemplo 250 ML y 1 L) porque así hay más ventas por producto y el pronóstico es más estable.

  • Cómo se calcula: se probaron 6 métodos pronosticando cada uno de los últimos 8 meses con solo lo que se sabía antes de ese mes, y se eligió el que mejor acertó para cada clase de producto: {% for clase, nombre in modelo.get('metodos', {}).items() %} clase {{ clase }}: {{ nombre }}{{ '; ' if not loop.last else '.' }} {% endfor %}
  • Venta esperada: las unidades que se espera vender ese mes, redondeadas hacia arriba. No es lo que hay que comprar: para saber cuánto reponer, las recomendaciones de abastecimiento descuentan el stock que ya hay y suman un margen de seguridad.
  • Tendencia: compara lo pronosticado con lo que se vendió el mes pasado. En productos de campaña puede indicar «baja» solo porque terminó la temporada, no porque el producto se venda peor.
  • Confiabilidad: qué tan bien acertó el método con ese producto en los últimos 8 meses: Alta (error bajo y ventas casi todos los meses), Media, Baja (el producto se vende poco o de forma muy irregular). {% set conf = modelo.get('confiabilidad', {}) %} {% if conf %}Hoy: {{ conf.get('Alta', 0) }} productos con confiabilidad Alta, {{ conf.get('Media', 0) }} Media y {{ conf.get('Baja', 0) }} Baja.{% endif %}

Límite honesto: muchos productos se venden pocas veces al año, y eso hace imposible acertar al detalle cada mes. Con confiabilidad Baja, tómalo solo como referencia; el sistema es más fiable para los productos de clase A.
